PetVora PawTag - new repository setup

1. Create a new GitHub repository (choose Private).
2. Upload ALL files from this folder: package.json, netlify.toml, the "public" folder and the "netlify" folder.
3. In Netlify: Add new site -> Import an existing project -> choose the repository -> Deploy.
4. Open the website. The PIN is leo@123.

To change the PIN later: Netlify -> Site configuration -> Environment variables -> add APP_PIN with the new PIN -> redeploy.

Do NOT rename or delete the Netlify site. QR codes use its address.
